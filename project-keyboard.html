Fracture

In Progress

Fracture is a custom mechanical keyboard designed from the PCB up, built around a rugged cyberpunk aesthetic. It ships as a family of three standalone devices — a full keyboard, a numpad, and a macropad — all sharing the same design language, firmware base, and companion software.

Each device features per-key addressable RGB, hot-swap switch sockets, USB-C connectivity, and QMK firmware running on an RP2350 microcontroller. A companion app ties everything together, handling RGB profiles, macro layers, and per-device configuration for all connected Fracture peripherals simultaneously.
