Project Portfolio

Fracture — Custom Keyboard Family Hardware / Firmware / Software

Designing a family of three custom mechanical keyboards (full layout, numpad, macropad) from the PCB up using KiCad — with no prior PCB design experience. Each device features per-key addressable RGB, Kailh hot-swap sockets, USB-C connectivity, and QMK firmware on an RP2350 microcontroller. A companion desktop app handles per-device RGB profiles, macro layers, and live configuration across all connected devices simultaneously.

KiCad RP2350 QMK Firmware WS2812B RGB PCB Design Embedded C USB-C
Ratch — AI-Powered Workshop Droid Robotics / AI / Fabrication

End-to-end design and build of a voice-activated workshop droid running entirely on local hardware — no cloud dependency. Engineered a complete AI pipeline: speech-to-text via Whisper, natural language generation via LLaMA 3.2 (Ollama), and character-tuned voice synthesis via edge-tts, all served through a FastAPI backend. The 3D printed Pit Droid-inspired body integrates seven servos for physical expression, controlled by a Raspberry Pi via PCA9685. Includes a persistent memory system and a tuned audio chain for character-accurate voice output.

Python FastAPI Raspberry Pi Whisper STT Ollama / LLaMA Servo Control 3D Printing CAD Audio DSP
Xenoforge — Browser-Based Factory Game Software / Game Dev / Systems Design

Designed and built a fully functional factory and logistics game running in a single HTML file — no engine, no dependencies, no install. Built a custom 2D tile renderer on HTML5 Canvas with a 60fps game loop, 500ms logic tick, and persistent state via localStorage. The game features 304 unique components across seven production tiers, a conveyor routing system, machine processing logic, a blueprint system for compressing sub-factories into reusable tiles, and a complete economy layer. Demonstrates deep understanding of complex system architecture, simulation design, and data-driven game mechanics.

JavaScript HTML5 Canvas Systems Architecture Simulation Design State Management Data Structures
RiftCast — 2D Sci-Fi Survival Game Software / Game Dev

A Terraria-inspired 2D survival and exploration game built in Godot 4.6. Features procedurally generated worlds with five depth layers, four biome zones, cave systems, four ore types with glow effects, and a vector-drawn player character rendered entirely in GDScript. Currently implementing inventory, crafting, and enemy systems on top of a working movement, mining, and HUD foundation.

Godot 4.6 GDScript Procedural Generation 2D Physics Vector Rendering
NFC Macros — Browser-Based NFC Tool Software / Hardware Interface

A browser-native tool for designing and writing custom NFC tag payloads — keyboard shortcuts, URL launchers, and multi-step macro sequences — using the Web NFC API. Writes directly to physical NFC tags from the browser without any native app or driver. Demonstrates hands-on knowledge of NFC/RFID protocols and modern browser hardware APIs.

Web NFC API JavaScript NFC / RFID NDEF Protocol

Designed a fully passive NFC business card as a custom PCB — NTAG213 chip, portrait orientation, black soldermask, ENIG gold finish. No battery, no components beyond the chip and antenna trace.
