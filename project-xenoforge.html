Xenoforge

In Progress

Xenoforge is a browser-based factory and logistics game set on the alien planet Kepler-7b. You play as a stranded engineer with a single directive: synthesize the Aetheric Singularity — the only power source capable of jumpstarting your ship's drive home.

To get there, you'll automate the production of 304 unique components spread across seven complexity tiers. Mine raw materials, chain processing machines together, route items with conveyor belts, and compress entire factories into reusable Blueprint blocks. Everything runs in a single HTML file — no install, no account, no dependencies.

HTML5 Canvas JavaScript Browser-Native No Install
