Robotics / AI

Ratch

In Progress

Ratch is a voice-activated workshop droid with an attitude. Built around a 3D printed Pit Droid-inspired body, Ratch communicates entirely through voice — no screen — and expresses itself physically through seven servos controlling its head, arms, antenna, and torso.

All AI processing runs locally: a laptop on the network handles speech recognition via Whisper, language generation via LLaMA 3.2, and voice synthesis tuned to match Ratch's personality. A Raspberry Pi on the droid itself manages audio I/O, servo control, and communication with the server — keeping the cloud out of the loop entirely.

Raspberry Pi Ollama / LLaMA 3.2 Whisper STT FastAPI Python 3D Printed
